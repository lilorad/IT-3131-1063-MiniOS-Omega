## 📖 Project Description

MiniOS Omega is a command-line operating system simulation written in Python. It demonstrates core OS concepts such as file management, process handling, and memory management in a simple, easy-to-use environment.

## ✨ Features

- Command-line interface
- File management
- Process simulation
- Memory simulation
- User login
- System information
- Error handling

## 🛠️ Requirements

Requirements:
- Visual Studio Code
- Programming Language: Python
- Windows CMD


## ▶️ How to Run

1. Clone repository
2. Open the project folder in Visual Studio Code.
3. Open Windows CMD (or the Visual Studio Code terminal) in the project folder.
4. Run the program in CMD:
   - cd "paste file location of VS code"
   - type python main.py
5. Run the program in Visual Studio code temrinal
   - type python main.py

## ⌨️ Available Commands

Here are the commands available in the MiniOS Omega 

*General

help – Show available commands
clear – Clear the screen
date – Show current date
time – Show current time
whoami – Show current user
systeminfo – Show system information
exit – Shut down MiniOS

*File System

dir – List files and folders
mkdir – Create a directory
create – Create an empty file
write – Write text to a file
read – Read a file
delete – Delete a file or empty folder
cd – Change directory

*Processes

process – Show running processes
run – Start a process
kill – Terminate a process by PID

*Memory

memory – Show memory status
allocate – Allocate memory (MB)
free – Release memory (MB)
