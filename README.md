## 📖 Project Description

MiniOS Omega is a command-line operating system simulation written in Python. It demonstrates core OS concepts such as file management, process handling, and memory management in a simple, easy-to-use environment.

## ✨ Features

- Command-line interface
- File management
- Process simulation
- Memory simulation
- User login
- System information
- Error handling

## 🛠️ Requirements

Requirements:
- Visual Studio Code
- Programming Language: Python
- Windows CMD


## ▶️ How to Run

1. Clone repository
2. Open the project folder in Visual Studio Code.
3. Open Windows CMD (or the Visual Studio Code terminal) in the project folder.
4. Run the program in CMD:
   - cd "paste file location of VS code"
   - type python main.py
5. Run the program in Visual Studio code temrinal
   - type python main.py
